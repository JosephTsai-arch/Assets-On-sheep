# 🐑 資產上羊 (AssetOnSheep) 多帳號智慧記帳系統

> **AssetOnSheep** 是一套專為現代個人、家庭與跨社交圈打造的**全方位多帳號智慧記帳與財務管理系統**。  
> 深度整合 **LINE 官方聊天機器人 (Messaging API)**、**LINE LIFF 內嵌原生網頁** 與 **React/Tailwind PWA 全功能網頁**，並搭載 **Google Gemini AI 雙引擎語意與發票視覺辨識 (OCR)**、**多幣別協作帳本**、**最小金流 AA 智慧平帳演算法** 以及 **動態沉澱儲蓄基金**。

## 一、項目解決甚麼問題

1. **記帳步驟繁複、難以持久養成習慣**：
   * 傳統記帳軟體必須手動解鎖手機、開啟 App、在多層下拉選單中尋找分類，出門在外極易怠惰放棄。
   * **解決方案**：只需在 LINE 聊天室輸入一句自然語言（如「晚餐 160 玉山卡」）或拍攝發票/收據照片，即可在 1 秒內自動解析入帳。

2. **社交出遊與朋友聚餐 AA 分帳混亂**：
   * 多人聚餐、情侶生活費、家庭共管帳本常常因代墊、幣別不同或多人非均等分帳而算不清，事後追帳困擾。
   * **解決方案**：獨立「好友共管帳本」支援多幣別（TWD/JPY/USD 等），內建**最小現金流平帳演算法 (Min-Cash-Flow Algorithm)**，以最少筆轉帳次數完成清算。

3. **單一流式記帳無法反映真實身家資產**：
   * 一般記帳僅記錄流水收支，無法區分現金皮夾、銀行帳戶、電子票證與信用卡負債，帳戶互轉時容易造成重複計算。
   * **解決方案**：完整支援資產子帳戶水位計算，提供「雙向原子轉帳（一扣一入）」與刪改即時回滾機制。

4. **大額非週期性支出（年度保險、換手機、稅費）造成現金流斷崖**：
   * 突發或年度性的大額開銷常破壞單月預算。
   * **解決方案**：內建「動態沉澱基金 (Sinking Funds)」，依剩餘月數動態計算「本月建議應存金額」，到期一鍵出帳自動展延。

5. **跨平台數據孤島與換機資料遺失**：
   * **解決方案**：支援 **Google OAuth** 與 **LINE LIFF** 雙向原子綁定與資料融合，帳號資料同步至雲端與本地快取。

## 二、核心主要功能

### 1. 🤖 雙端對稱無縫聯動 (LINE Bot + LIFF + Web SPA)
* **一句話自然語言記帳**：AI 語意自動萃取品名、金額、日期、支付錢包與帳本分類。
* **發票與收據拍照 OCR**：支援傳統紙本發票、電子發票證明聯、店家小白單與刷卡簽單，內建民國年自動轉西元年。
* **4 列官方 Flex Message 卡片**：
  * 第 1 列：一鍵直接進入記帳軟體。
  * 第 2 列：快速切換交易分類（自動排除重複）。
  * 第 3 列：選擇扣款帳戶與設定分帳成員。
  * 第 4 列：確認入帳 / 放棄草稿。
* **底端狀態機快捷列 (Quick Reply)**：恆駐於對話框下方，包含【📱 軟體&功能】、【🔄 修改上一筆】、【👤 我的帳號】。
* **每日記帳提醒鬧鐘 (Line Push)**：使用者可自訂提醒時間與重複頻率，定時推播親切提醒。

### 2. 🤝 獨立好友名單與多幣別共管帳本
* **虛擬好友防污染隔離**：新註冊用戶自動生成名下專屬虛擬成員（如小美、阿倫、媽媽），絕對隔離不同用戶的社交資料。
* **LINE 好友邀請專屬連結**：透過 LIFF 授權雙向好友綁定。
* **多幣別獨立計價**：支援 TWD、JPY、USD、EUR、CNY、KRW、GBP、HKD 等幣別，並提供基準匯率換算。
* **Min-Cash-Flow 智慧平帳**：群組出遊多筆代墊後，演算法自動算出淨債權與最佳平帳路徑。

### 3. 💳 真實資產錢包與動態沉澱基金
* **多錢包管理**：現金皮夾、銀行活存、玉山帳戶、LINE Pay、街口支付與信用卡等。
* **雙向原子轉帳**：子帳戶互轉自動產生收支雙向配對，刪除或修改時餘額即時復原。
* **動態沉澱基金公式**：
  $$\text{剩餘期數} = \max(1, \text{目標年月} - \text{當前年月})$$
  $$\text{本月建議應存金額} = \frac{\text{目標總金額} - \text{已累積預存金額}}{\text{剩餘期數}}$$
  支出到期月提供「一鍵入帳」，自動扣減目標錢包並自動展延至次年。
* **真實聯動預算進度條**：動態彙整當月實際支出，即時呈現超支警示。

### 4. 🧠 Gemini AI 專業財務健檢 (嚴格經濟學/會計學術語)
* 依據經濟學與會計學架構分析財務結構，**嚴格杜絕生物學或醫學生理比喻**。
* 指標涵蓋：**恩格爾係數 (Engel's Coefficient)**、收支儲蓄率、流動性防護倍數、高槓桿負債預警與資產分散度評估。

### 5. 👑 管理員專區與災難應變
* **全站排行榜**：包含每月收支排行、大額支出審查（真實姓名與頭貼呈現）。
* **全域系統金鑰管理 (Tab 5)**：集中配置 LINE Channel Secret、Access Token、LIFF ID、Gemini API Key。
* **密碼學 8 位數緊急救援碼**：支援本機記憶體與磁碟雙軌備援，在雲端資料庫受限時仍能秒發秒解。
* **防暴力破解保護**：IP 失敗次數限制防爆破機制，以及深層資料軟刪除復原（Soft Delete Recovery）。

* **人工智慧**：Google Gemini 2.5 Flash / 1.5 Flash (`@google/genai`)

## 四、安裝與環境建置方法

### 1. 環境需求
* **Node.js**：`>= 18.0.0`
* **npm**：`>= 9.0.0`
* **Google Cloud / Firebase 專案**（開啟 Firestore 與 Firebase Authentication）
* **LINE Developers 帳號**（申請 Messaging API Channel 與 LIFF App）
* **Google Gemini API Key**

### 2. 複製專案與安裝依賴
```bash
git clone https://github.com/your-username/AssetOnSheep.git
cd AssetOnSheep
npm install
```

### 3. 環境變數設定
建立 `.env` 檔案（可參考 `.env.example`）：
```env
# 服務埠號 (預設 3000)
PORT=3000
NODE_ENV=development

# 應用公開網址 (本地測試可搭配 ngrok)
APP_URL=https://your-domain.run.app

# Google Gemini API 金鑰
GEMINI_API_KEY=your_gemini_api_key_here

# LINE Messaging API 配置 (亦可在管理員後台 Tab 5 直接動態配置)
LINE_CHANNEL_SECRET=your_line_channel_secret
LINE_CHANNEL_ACCESS_TOKEN=your_line_channel_access_token
LINE_LIFF_ID=your_line_liff_id_here
```

### 4. 啟動本機開發伺服器
```bash
npm run dev
```
啟動後伺服器將在 `http://localhost:3000` 運行，同時掛載 Express API 路由與 Vite 熱重載。

### 5. 專案建置與正式啟動
```bash
# 編譯打包前端靜態資產
npm run build

# 啟動正式伺服器
npm start
```

## 五、詳細使用方法

### 1. LINE 聊天機器人端操作
1. **單筆記帳**：在聊天室直接發送文字（例如：`午餐 120 現金`）。
2. **拍照辨識**：拍攝收據、發票並上傳至聊天室，機器人將自動解析並回傳 Flex 確認卡片。
3. **多人分帳**：輸入 `聚餐 2400 跟小美阿倫平分`，系統將自動比對成員並產生均分明細。
4. **修改上一筆**：點擊底端快捷列【🔄 修改上一筆】，或直接打字 `改金額 150`。
5. **軟體與功能中心**：點擊底端快捷鍵【📱 軟體&功能】，可喚出全功能卡片，點擊【📱 打開軟體】即以 LINE 原生視窗開啟系統。

### 2. Web / LIFF 網頁端操作
* **總覽視圖**：即時掌握資產淨值、當月總收入、總支出與本月結餘，提供當月消費結構長條圖與沉澱基金快速卡片。
* **記帳明細**：頂部具備「帳本切換器」與「月份選擇器」，支援關鍵字搜尋、交易編輯、雙向轉帳記錄檢視與軟刪除。
* **資產與預算**：管理各錢包餘額、設定月度預算警戒線，以及規劃年度保險、換機專屬沉澱基金。
* **好友共管**：建立旅行或家庭帳本，設定計價幣別，檢視成員代墊明細與點擊【一鍵平帳】。
* **管理員專區 (Super Admin)**：切換月份檢視全站收支排名、大額開銷，以及於 Tab 5 統一管理系統全域金鑰與密鑰。

## 六、輸入與輸出範例

### 範例 1：自然語言日常記帳
* **用戶在 LINE 輸入**：
  ```text
  午餐吃牛肉麵 180 街口支付
  ```
* **系統處理邏輯**：
  * 金額：`180`
  * 項目：`牛肉麵`
  * 分類：自動歸類為 `餐飲美食`
  * 扣款帳戶：自動配對至 `街口支付` 錢包
* **LINE 輸出 (Flex Message 卡片)**：
  ```
  ┌────────────────────────────────────┐
  │ 🐑【記帳確認】                      │
  │ 餐飲美食 - 牛肉麵                  │
  │ 金額：TWD $180                     │
  │ 帳戶：街口支付                      │
  ├────────────────────────────────────┤
  │ [📱 進入軟體查看] [✏️ 改分類]       │
  │ [💳 改帳戶]       [🔄 改金額]       │
  │ [✅ 確認入帳]                       │
  └────────────────────────────────────┘
  ```

### 範例 2：社交 AA 多人平帳
* **用戶在 LINE 輸入**：
  ```text
  好市多採買 3600 跟小美阿倫平分
  ```
* **系統處理邏輯**：
  * 辨識出成員包含：本人、小美、阿倫（共 3 人）
  * 每人均攤：`$1,200`
  * 產生分帳詳細清單 (`split_details`)
* **LINE 輸出**：
  回傳均分確認卡片，明細列出「本人代墊 $3,600，小美應付 $1,200，阿倫應付 $1,200」，確認入帳後自動記入共管帳本。

### 範例 3：發票/收據拍照辨識
* **用戶在 LINE 上傳**：
  * 拍攝便利超商電子發票證明聯照片。
* **Gemini 視覺模型辨識輸出**：
  * 店家名稱：`統一超商`
  * 交易日期：自動將發票上的民國 `115年10月18日` 轉換為西元 `2026-10-18`
  * 品項明細：`無糖豆漿 $35`、`茶葉蛋 $14`，總計 `$49`
* **LINE 輸出**：
  即時回傳發票商品明細草稿卡片供核對入帳。

### 範例 4：批量流水記帳
* **用戶在 LINE 或軟體內貼上**：
  ```text
  10/18 早餐 65 現金
  10/18 加油 150 信用卡
  10/18 屈臣氏生活用品 420 玉山帳戶
  ```
* **系統輸出**：
  自動解析為 3 筆待審草稿，並支援「一鍵全部入帳」批次寫入資料庫。

### 範例 5：AI 財務健檢報告分析 (經濟學模型)
* **輸入條件**：當月生活必需支出 $25,000、投資配置 $10,000、總收入 $60,000。
* **Gemini 財務健檢輸出**：
  ```markdown
  ### 📊 財務結構經濟學分析報告
  * **恩格爾係數 (Engel's Coefficient)**：41.6%（生活最終消費支出控制良好）
  * **儲蓄與資本形成率**：58.3%（資本積累穩健）
  * **流動性防護倍數**：儲備資金充沛，相當於 4.2 個月日常現金流
  * **總體評價**：資產流動性充裕，建議將部分無息現金調撥至固定收益標的以對抗通膨。
  ```

## 七、安全性與系統健壯性設計

1. **斷路器機制 (Circuit Breaker & Dual Cache)**：
   * 內建 Firestore 免費配額自動探測，當每日 5 萬次讀取額滿時，系統自動啟動斷路保護，秒級切換為本地磁碟與記憶體快取模式，拒絕白屏或逾時當機。
2. **反巨型單體規範 (Anti-God Object)**：
   * 單一 UI 組件嚴格限制在 300 行以內，Services 模組限制在 400 行以內，高度模組化且易於維護擴充。
3. **資料隔離與軟刪除安全網**：
   * 所有資料均強制綁定 `user_id` 嚴密隔離。所有刪除皆為標記 `deletedAt` 軟刪除，防止誤刪事故。
4. **遞迴資料消毒過濾 (`cleanForFirestore`)**：
   * 在將物件寫入資料庫前，自動遞迴去除所有 `undefined` 屬性，杜絕 Firestore SDK 崩潰報錯。
5. **原型鏈污染防禦 (Prototype Pollution Guard)**：
   * 伺服器入口嚴格檢查 `__proto__`、`constructor` 等非法欄位注入，確保後端 API 安全無虞。
